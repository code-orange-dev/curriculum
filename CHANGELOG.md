# Changelog

What changed in the curriculum, newest first. Small fixes are in the [commit history](https://github.com/code-orange-dev/curriculum/commits/main).

## November 2026

**Decoding Bitcoin, rebuilt for the 10-week cohort**
- The syllabus follows [Decoding Bitcoin](https://bitcoindevs.xyz/decoding) by The Bitcoin Dev Project (#7). Every week has a guide, exercises, model answers, facilitator slides and notes (#7).
- All 10 regtest labs were run end to end on Bitcoin Core 29.0, with measured numbers in the solutions (#8). Weeks 1-2 were checked again on Bitcoin Core 32.1 by a contributor (#15).
- Python labs for weeks 3 and 4 grade your code against real mainnet transactions (#7).
- The old weeks on Bitcoin Core and first contributions moved to [After the cohort](./decoding-bitcoin/after-the-cohort.md) (#7).
- Facilitator slides are built automatically into web slides and PDFs (#8).

**New material**
- 7 workshop facilitator guides: multisig, nodes, mining, BTCPay, ecash, Nostr, privacy (#8)
- 6 Nostr developer workshop modules with working code (#7)
- Week pages for rawBit and Sovereign Bitcoiner (#8)

**For contributors**
- Issue forms, a pull request template and [good first issues](https://github.com/code-orange-dev/curriculum/labels/good%20first%20issue) (#8)
- The link checker now checks `#heading` links too and runs on every pull request (#7)

## Earlier

- Privacy Track Season One: opens with Silent Payments, new labs (#2)
- Bitcoin Dojo weeks 3-7: exercises graded against real Bitcoin data (#3)
- Dead links fixed, accuracy cleanup (#4, #5)
