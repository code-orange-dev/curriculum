# Finding a Contribution Target

This page deliberately lists **no specific issues**. A hand-picked list goes stale within days as issues get closed, claimed or fixed, and a stale list sends people at work that no longer exists. Instead, each session links to live searches, and a facilitator confirms a target the morning of the session.

## Before anyone starts work on an issue

Check all of these on the day, not from memory:

1. **Still open**, and no linked or cross-referenced PR is already fixing it (read the issue's timeline)
2. **Unassigned**, and nobody has said "I'll take this" in the comments recently
3. **Still wanted**: labelled `good first issue` / `help wanted`, or a maintainer has said so
4. **Small enough** to make real progress on in or shortly after a session
5. You've read the repo's CONTRIBUTING file, and you **comment on the issue before starting**

If a search comes back empty, that's normal: pick a **test target** instead (below), or ask in the project's chat what kind of help is useful right now.

## Test targets (often the better first contribution)

Building an open PR, running it on your machine and posting a precise test report is useful to maintainers and doesn't compete with anyone. Use the "open PRs" links below, read the thread first, and follow the report format in [PR_CHECKLIST.md](./PR_CHECKLIST.md). Only post if your report adds something the thread doesn't already have.
